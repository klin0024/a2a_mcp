# 飲食紀錄分析

## 步驟

### 1. 釐清紀錄內容

- 列出使用者吃的每一樣食物。
- 份量不明確時，追問或用常見份量並註明假設（例如「便當白飯以 220 g 計」）。
- 照片分析：辨識食物與大致份量，**主動說出你的假設**，請使用者修正。照片估算誤差通常很大，要說明這一點。
- 別忘了問：飲料、零食、醬料、宵夜。

### 2. 查詢營養成分

每個品項交給 `food-database-lookup`。

### 3. 加總與比較

與 `energy-needs-calc` 算出的目標比較。沒有個人目標時，用一般成人 DRIs 比較，並說明這只是參考。

重點檢查：
- 熱量、蛋白質、脂肪、醣類
- 膳食纖維（成人每日 25–35 g）
- 鈉（每日 < 2,400 mg；高血壓者 < 2,000 mg）
- 添加糖（建議 < 總熱量 10%）
- 六大類是否齊全，尤其是蔬菜、水果、乳品

### 4. 給出建議

- **先講做得好的地方**，再講需要調整的地方。
- 只挑 **1–3 個影響最大的改變**，並給具體可行的替代方案。
  - 不好的例子：「要少吃油」
  - 好的例子：「排骨便當換成滷雞腿便當，主菜不吃外皮，大約可以少 150 大卡」
- 不使用「垃圾食物」「罪惡」「爆卡」這類字眼。

## 輸出格式

```
【今日飲食分析】
| 餐次 | 內容 | 熱量 | 蛋白質 |
|---|---|---|---|
| 早餐 | 鮪魚蛋餅＋中杯奶茶 | 約 500–580 | 約 14 g |
| 午餐 | 排骨便當 | 約 750–900 | 約 28 g |
| 晚餐 | 牛肉麵 | 約 650–800 | 約 30 g |
| 點心 | 半糖珍奶（大杯） | 約 400–500 | 約 4 g |
| 合計 | | 約 2,300–2,780 kcal | 約 76 g |

目標：1,400–1,500 kcal ／ 蛋白質 75–90 g

✅ 做得好：蛋白質已經接近目標
🔧 建議調整：
1. 珍奶改成無糖茶或鮮奶茶 → 約少 300–400 大卡
2. 排骨便當換成滷雞腿便當、去皮 → 約少 150–200 大卡
3. 蔬菜明顯不足：晚餐加一份燙青菜
```

## 安全提醒

- 使用者記錄的熱量長期明顯低於 BMR，或流露出對吃東西的罪惡感、補償性運動、催吐 → 立即套用 `red-flag-screening`，不要給減量建議。
