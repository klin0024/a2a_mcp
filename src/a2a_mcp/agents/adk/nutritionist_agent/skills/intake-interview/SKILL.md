# 初診問診

## 目標

用 2–4 輪對話蒐集足夠資料，建立「個人營養檔案」，供後續的 skill 使用。不要一次丟出一整張問卷。

## 要蒐集的資料

### 第一輪：基本資料（必要）
- 年齡、生理性別
- 身高、體重（如果使用者不想提供體重，尊重他的選擇，改用一般原則）
- 主要目標：減重／增肌／維持／控制血糖／控制血壓／改善腸胃／懷孕期營養／其他

### 第二輪：健康狀況（必要）
- 已知疾病：糖尿病、高血壓、高血脂、腎臟病、痛風、甲狀腺、腸胃疾病等
- 正在使用的藥物與保健食品
- 食物過敏或不耐（例如乳糖、麩質、海鮮）
- 是否懷孕或哺乳

### 第三輪：生活型態
- 活動量：工作型態（久坐／站立／勞動）＋每週運動的頻率、時間與種類
- 一日飲食型態：幾餐、外食比例、常吃哪裡（自助餐、便利商店、早餐店）
- 飲食限制：素食（全素／蛋奶素／方便素）、宗教、不吃的食物
- 預算與烹飪能力

### 第四輪（選填）
- 睡眠、壓力、飲酒、含糖飲料頻率
- 最近一次的健檢數值（血糖、HbA1c、血脂、尿酸、腎功能）

## 問法原則

- 每輪最多問 3–4 個問題，並說明為什麼要問（例如「問用藥是因為有些藥會和食物互相影響」）。
- 使用者已經主動提到的資訊不要再問。
- 使用者想先拿到答案時，先用現有資料給初步建議，再補問。
- 提問過程中持續套用 `red-flag-screening`。如果出現飲食疾患徵兆，**不要再問體重目標**，改走安全流程。

## 輸出：個人營養檔案

蒐集完畢後，整理成以下格式，向使用者確認內容正確：

```
【個人營養檔案】
基本：女，34 歲，160 cm，62 kg（BMI 24.2）
目標：減重 5 kg，3–4 個月內
健康：輕度高血脂；無用藥；對蝦過敏
活動：辦公室久坐；每週慢跑 2 次 × 30 分鐘 → 活動等級：輕度活動
飲食：三餐外食為主（早餐店、公司附近便當）；蛋奶素
其他：每天一杯半糖手搖飲；睡眠約 6 小時
轉介註記：無
```

確認後，轉交 `energy-needs-calc`。
