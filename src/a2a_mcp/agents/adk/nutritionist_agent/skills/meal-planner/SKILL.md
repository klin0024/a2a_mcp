# 菜單規劃

## 前置條件

- 需要個人營養目標（來自 `energy-needs-calc`）。沒有的話，先問基本資料，或以一般成人 1,800–2,000 kcal 為例並說明。
- 確認：外食或自煮、預算、素食或其他限制、過敏、不喜歡的食物、可以準備餐點的時間。

## 規劃原則

1. **對準目標**：每日熱量在目標範圍內，蛋白質平均分配於三餐（每餐約 20–30 g）。
2. **六大類齊全**：每天都要有蔬菜、水果、乳品（或替代品）、全穀雜糧。
3. **在地且買得到**：以台灣超市、傳統市場、超商、自助餐、便當店買得到的食物為主。
4. **可重複**：一週菜單可以重複食材，減少採買與備料負擔。外食族不必每天都不同。
5. **疾病調整**：
   - 糖尿病：每餐醣類量接近，搭配蛋白質與蔬菜，水果分次吃
   - 高血壓：少加工肉品、醃漬物、湯汁；多蔬果與乳品
   - 高尿酸：避免內臟、濃肉湯、大量海鮮；不配酒
   - 慢性腎臟病：**不規劃具體菜單**，請使用者與醫院營養師討論
6. 菜單上的熱量數字交給 `food-database-lookup` 估算，用範圍表示。

## 外食族的搭配範例

| 情境 | 建議搭配 |
|---|---|
| 超商早餐 | 茶葉蛋 2 顆＋無糖豆漿＋地瓜 |
| 自助餐 | 半碗至一碗飯＋1 份非油炸主菜＋2–3 樣青菜（瀝湯汁） |
| 便當店 | 選滷、烤、蒸的主菜；飯量減 1/3；加點一份燙青菜 |
| 麵店 | 乾麵或湯麵（不喝完湯）＋燙青菜＋滷蛋或豆干 |
| 早餐店 | 蛋餅或飯糰＋無糖豆漿；少選油炸類與奶精奶茶 |

## 輸出格式

### 一日菜單

```
【一日菜單｜約 1,500 kcal｜蛋奶素】
| 餐次 | 菜色 | 熱量 | 蛋白質 |
|---|---|---|---|
| 早餐 | 全麥吐司 2 片＋荷包蛋＋無糖豆漿 400 ml | 約 380 | 約 23 g |
| 午餐 | 自助餐：糙米飯半碗、滷豆腐、炒高麗菜、燙地瓜葉 | 約 500 | 約 20 g |
| 點心 | 無糖優格＋芭樂半顆 | 約 150 | 約 8 g |
| 晚餐 | 番茄豆腐蛋花湯麵＋燙青菜 | 約 470 | 約 24 g |
| 合計 | | 約 1,500 kcal | 約 75 g |
```

### 一週菜單

使用者要一週菜單時，加上：
- 每天一張表（或一張 7 天的總表）
- **採買清單**：依類別（蔬菜、蛋白質、主食、乳品、水果、其他）列出總量
- **備料提示**：週末可以先煮好的食物（例如滷雞腿、水煮蛋、糙米飯分裝冷凍）

## 最後附註

- 提醒菜單可以彈性替換：同類食物互換（例如雞胸換成豆腐）熱量差不多即可。
- 第一次提供個人化菜單時，附上 system prompt 規定的一般衛教提醒。
