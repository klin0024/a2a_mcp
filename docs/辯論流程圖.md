# 爭議性評論文章 — 辯論協調流程

以下流程圖說明協調者如何取得正/反/中立三方觀點，彙整、撰稿並自我審查，直到產出定稿。

```mermaid
flowchart TD
    A[🗣️ 給定一個有爭議的主題] --> B[找三個角色<br/>各自準備開場說法]

    B --> B1[😊 正方<br/>只講支持的理由]
    B --> B2[😠 反方<br/>只講反對的理由]
    B --> B3[😐 中立方<br/>只講客觀事實數據]

    B1 & B2 & B3 --> C[讓正反雙方<br/>互相看到對方的開場說法]

    C --> D1[正方針對反方<br/>提出反駁]
    C --> D2[反方針對正方<br/>提出反駁]

    D1 & D2 --> E[請中立方<br/>評論這輪交鋒<br/>誰有憑有據、誰偏主觀]

    E --> F[請三方各自<br/>用一段話總結自己的重點]

    F --> G[📝 把三方所有發言<br/>整理成一份觀點摘要]

    G --> H[✍️ 根據摘要<br/>寫出文章初稿]

    I{🔍 自己檢查一遍<br/>論述夠不夠平衡？<br/>有沒有明顯漏洞？}
    H --> I

    I -->|不夠好，且還沒改超過4次| J[參考整份初稿<br/>照檢查意見修改]
    J --> I

    I -->|通過| K[✅ 定稿]
    I -->|改了4次還是不夠好| L[⏸️ 先停下來<br/>交出目前最好的版本<br/>並說明還有哪些問題沒解決]

    K --> M[交給使用者：<br/>完整文章 + 三方重點摘要]
    L --> M
```

## 流程說明

1. **開場立論**：正方、反方、中立方各自獨立準備開場說法，互不參考。
2. **交叉反詰**：正反雙方看到對方的開場論點後，各自提出反駁。
3. **中立方講評**：中立方針對這輪交鋒做客觀分析，指出哪些論點有資料支持、哪些偏主觀推論。
4. **三方重申重點**：三方各自用一小段話總結自己最核心的主張。
5. **彙整摘要**：把三方所有發言整理成一份完整的觀點摘要。
6. **撰寫初稿**：根據摘要寫出文章第一版。
7. **自我審查**：檢查論述是否平衡、有無漏洞，不通過則參考整份初稿修改，最多重複 4 次。
8. **輸出定稿**：審查通過即完稿；若 4 次仍未通過，則交出目前最佳版本並附註未解決的問題。
