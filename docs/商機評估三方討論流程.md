# 商機評估討論流程（簡化版）

市場分析、財務評估、客戶需求三個角色一起評估一個商機，不是吵架辯論，而是互相檢查對方的想法有沒有道理。

```mermaid
flowchart TD
    A[🎯 有一個新商機的點子] --> B[三個人<br/>各自先想一想]

    B --> B1[📊 市場的人想：<br/>這個市場夠大嗎？<br/>現在做時機好嗎？]
    B --> B2[💰 算錢的人想：<br/>要花多少成本？<br/>賣多少錢才賺？]
    B --> B3[🙋 懂客戶的人想：<br/>客戶真的有這個困擾嗎？<br/>他們願意花錢解決嗎？]

    B1 & B2 & B3 --> C[三人互相提問]

    C --> D1[算錢的人問市場的人：<br/>你說市場很大<br/>是真的算過還是用猜的？]
    C --> D2[懂客戶的人問算錢的人：<br/>你訂的價格<br/>客戶真的付得起、願意付嗎？]
    C --> D3[市場的人問懂客戶的人：<br/>你訪問到的這些人<br/>能代表大部分客戶嗎？]

    D1 & D2 & D3 --> E[三人重新調整<br/>自己原本的想法]

    E --> F[📝 三人一起<br/>寫出一份簡單結論：<br/>這個市場好不好、算不算划算、<br/>客戶要不要買單]

    F --> G{該怎麼決定？}
    G --> G1[✅ 可以做]
    G --> G2[🔍 還要再多調查一下]
    G --> G3[⛔ 先不要做]

    G1 & G2 & G3 --> H[說明<br/>還有哪些不確定的地方]
```

## 流程說明（白話版）

1. **各自先想一想**：市場、算錢、懂客戶三個人，各自先憑自己的專業提出初步看法，不互相討論。
2. **三人互相提問**：
   - 算錢的人問市場的人：你說的市場規模，是有根據，還是憑感覺?
   - 懂客戶的人問算錢的人：你訂的價格，客戶真的願意付嗎？
   - 市場的人問懂客戶的人：你問到的這些客戶，能代表大多數人嗎？
3. **重新調整想法**：每個人聽了對方的質疑後，補充資料或修改自己原本的判斷。
4. **寫出結論**：三人一起把最後的看法整理成一份簡單的結論——市場好不好、划不划算、客戶要不要買單。
5. **決定怎麼做**：根據結論，選「可以做 / 再多調查 / 先不要做」，並說清楚還有哪些地方沒把握。
